# Contributing to MidiSorting

Thank you for your interest in improving **MidiSorting**!

## Development Workflow
1. Create a new branch from `main` using a descriptive prefix (`feat/`, `fix/`, `docs/`).
2. Ensure any changes to `organizer/` are covered by unit tests in `tests/`.
3. Run the test suite locally using `pytest` before opening a Pull Request.
4. Open a Pull Request targeting `main` with a clear summary of changes.
